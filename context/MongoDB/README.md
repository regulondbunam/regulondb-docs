# Copia de colecciones core (agosto de 2025)

Esta carpeta contiene una exportación JSON de las colecciones de `regulondbmultigenomic` de **agosto de 2025** (fecha de los archivos; probablemente corresponde a la release 14.0.0), anterior a la release 14.5.1.

- **No es la referencia vigente.** La documentación de `07_technical_reference/core_collections/` se generó con la exportación de la release **14.5.1** (11 de noviembre de 2026) y sus esquemas de validación, que se conservan junto con las demás versiones en la unidad compartida del proyecto (`RegulonDB-Releases/14.5/.../RegulonDB-Multigenomic`).
- Los identificadores de algunos objetos (por ejemplo, promotores, operones y unidades de transcripción) difieren entre esta copia y la release 14.5.1. Para cualquier ejemplo o análisis se deben usar los identificadores de la release vigente.
