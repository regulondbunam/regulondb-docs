# Version History

The complete history of RegulonDB releases is published and kept up to date on the RegulonDB website:

- **Release history:** [https://regulondb.ccg.unam.mx/summaryHistory](https://regulondb.ccg.unam.mx/summaryHistory)

For each release, the history lists the version number and release date, and links to its release note. Each release note includes the EcoCyc version used, a summary of new content and updates, the counts of objects for that release, and a **DOWNLOAD** link to the release dump (see [Database Dumps](../02_data_access/database_dumps.md)).

To cite a specific release, see [How to Cite RegulonDB](../00_about_policies/how_to_cite.md).
