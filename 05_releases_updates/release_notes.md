# Release Notes

Release notes are generated with each RegulonDB release and published on the RegulonDB website. Open the release history and select a version to read its note:

- **Release history and notes:** [https://regulondb.ccg.unam.mx/summaryHistory](https://regulondb.ccg.unam.mx/summaryHistory)

Each release note describes:

- The RegulonDB version, release date, and the EcoCyc version used for gene and product annotation.
- A summary of new content and updates (for example, new or updated promoters, transcription factors, conformations, and regulatory interactions).
- The counts of objects in that release.

Each note also offers a **DOWNLOAD** link to the complete release dump (see [Database Dumps](../02_data_access/database_dumps.md)).
